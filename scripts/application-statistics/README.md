# Application Statistics

Generates statistics from SwampHacks application export.

The script can report information such as:

- Total applications
- UF vs. non-UF applicants
- Schools represented
- Class-year distribution
- First-year applicants
- Hackathon experience
- Majors
- Referral sources
- Shirt sizes
- Dietary requirements
- Graduation years

## Usage

Place the application CSV in this directory:

```text
applications.csv
